Scope and privacy

See where your library data goes.

Your catalogue stays on this computer

  • No product account or cloud catalogue
  • No analytics, advertising, or background network requests
  • WebDAV details are never written to app storage

Transfers happen only when you start them

  • USB copies go to the folder you choose
  • WebDAV sends selected books to your server
  • The app clears the password after each attempt

WebDAV is included. Check the connection first to get specific help for address, sign-in, permission, and storage errors.
