Plain-language policy · 1 September 2026

How the app handles your data.

The app sends no background network requests. A WebDAV transfer starts only when you request it.

Data the app stores

The app stores your catalogue, collections, preferences, and imported highlights on your computer.

Source book files are read for metadata and are not rewritten.

Transfers you request

USB copies go only to the folder you choose.

For WebDAV, selected books, folder names, and sign-in details go only to the server address you provide. That server’s privacy terms apply.

The app does not write the WebDAV address, username, or password to app storage. The password clears after every check or sync attempt.

Website and demo

This website sets no analytics or advertising cookies. The demo’s service worker stores its public files after the first sample visit.

The landing page asks GitHub’s public releases API for current download links. GitHub receives normal request details, including your IP address and browser headers.

The demo uses a separate browser storage key. Leaving the demo never copies sample data into your real app library.

Your control

Clear app storage or uninstall the app to remove its local data.

Book copies and Markdown exports remain where you placed them. Email privacy@sociobot.in with privacy questions.
